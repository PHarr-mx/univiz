# 工具契约与能力检查

仅在工具存在性、renderer 能力、原图 URL 或事实核验权限不明确时读取。

## 原则

本 Skill 只使用当前环境明确提供的事实核验、原图读取、ECharts、renderer 和图片生成能力。调用前查看工具与参数，只提交明确支持的字段。

## 搜索与事实核验

当任务涉及可能变化的信息、真实数据、年份、人物、事件顺序或专业细节时，使用当前可用的官方搜索、链接访问或数据工具核验。

- 搜索查询聚焦当前图所需事实，避免把整篇搜索结果塞进图中。
- 无法获得可靠结果时，不绘制伪造的真实图表、时间线、关系或架构；提供模板、空态、取数方案或结构化文字。

## 图片搜索与原图

图片搜索只用于用户明确需要真实素材或核验实体外形的场景，不用于寻找抽象概念图冒充权威机制图。

- 原图作为证据时保持其像素内容、对象位置和比例。HTML 可使用获授权的 data URI、随文档提供的相对资源或真实 HTTPS URL。
- 根据原图观察自绘结构时，只使用直接可见特征，并明确标注“示意”。

## ECharts

普通精确数据图默认交付 `portable-output.md` 规定的完整 HTML，option 在文档内部初始化和绘制，并保留静态图或数据表降级。只有用户明确要求 option-only 时，才只提供原生 `echarts` option。

## HTML 输出

HTML/SVG 与 ECharts 输出遵循 `portable-output.md`。renderer 是可选的宿主展示/传输方式，不是唯一产物；宿主不支持时仍交付独立 HTML 文件或完整 HTML 源码。

1. 交互 HTML/SVG 改为静态 HTML/SVG。
2. 外部库改为纯 HTML/SVG/Canvas。
3. renderer 整体不可用时改为结构化文字或原图说明。

## 失败处理

- 工具不存在或无权限：说明限制，不猜测私有 API、不绕过鉴权。
- 外部库失败：显示静态替代或可读提示。
- 原图 URL 不可访问：不输出空白叠加层。
- 数据或事实不足：不通过视觉形式伪装确定性。

## 生成式知识配图

仅在路由选中 `generated_illustration` 时调用图片生成工具，先按 `mode-generated-illustration.md` 读取完整分支规范。工具名、参考图、尺寸、批量和模型版本参数均以当前 schema 为准，具体示例见 `generated-tool-contracts.md`。

生成后检查可见文字、构图、事实和参考图特征；无法读取结果时不声称已完成视觉检查。部分失败只重试失败项，每项最多重试一次；仍失败时保留文字，或在结构可靠时改用静态 HTML/SVG。
